# Uložit všechny obrázky v adresáři dat

Přesunout všechny obrázky uložené v souboru rodokmenu do samostatných souborů ve složce souboru rodokmenu.

Uložení obrázků do samostatných souborů udržuje soubor rodokmenu malý. Rodokmen musí být nejprve uložen do souboru. Aplikace si nejprve vyžádá potvrzení. Změna se projeví až po uložení rodokmenu.
