# Uložit všechny obrázky v rodokmenu

Přesunout všechny obrázky uložené v datové složce do souboru rodokmenu.

Každý obrázek přesunutý do rodokmenu se zmenší tak, aby zabíral nejvýše 256 KB. Aplikace si nejprve vyžádá potvrzení. Změna se projeví až po uložení rodokmenu, soubory obrázků, které se již nepoužívají, se po uložení rodokmenu odstraní.
