# Obnovit výchozí rozvržení

Uspořádat panely a panely nástrojů hlavního okna tak, jak jsou po prvním spuštění.

Diagram rodokmenu je uprostřed okna. "Osoby" a "Vztahy" jsou na kartách vlevo, nad "Podrobnostmi osoby". "Chat AI" a "Dotaz AI v Cloud" jsou na kartách vpravo a "Výstup" je dole, jsou skryté a lze je zobrazit z nabídky "Zobrazit". Panely oddělené do samostatných oken se vrátí zpět do hlavního okna. Velikost hlavního okna se nezmění.
