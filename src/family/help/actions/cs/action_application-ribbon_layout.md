# Rozložení s pásem karet

Zobrazit příkazy na pásu karet místo nabídek a panelů nástrojů.

Pás karet seskupuje příkazy na kartách "Rodokmen", "Osoby", "Vztahy" a "Cloud a AI". Nabídka "Soubor", "Uložit", Cloud, nastavení aplikace a nápověda zůstávají v řádku se záložkami karet. Dvojklikem na záložku se pás karet sbalí na záložky. Volba se zapamatuje.
