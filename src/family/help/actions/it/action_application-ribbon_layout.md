# Layout a barra multifunzione

Mostra i comandi in una barra multifunzione anziché in menu e barre degli strumenti.

La barra multifunzione raggruppa i comandi nelle pagine "Albero genealogico", "Persone", "Relazioni" e "Cloud e IA". Il menu "File", "Salva", Cloud, le impostazioni dell'applicazione e la guida restano nella riga delle schede delle pagine. Fare doppio clic su una scheda per comprimere la barra multifunzione alle sole schede. La scelta viene ricordata.
