# Memorizza tutte le immagini nella cartella dei dati

Spostare tutte le immagini archiviate nel file dell'albero genealogico in file separati nella directory del file dell'albero genealogico.

Archiviare le immagini in file separati mantiene piccolo il file dell'albero genealogico. Prima l'albero genealogico deve essere salvato in un file. L'applicazione chiede prima una conferma. L'albero genealogico deve essere salvato perché la modifica abbia effetto.
