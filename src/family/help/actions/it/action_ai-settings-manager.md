# Gestore impostazioni IA

Gestire gli agenti IA usati dalla chat IA.

Per ogni agente IA impostare il tipo di API, la chiave API, l'URL e il modello e, facoltativamente, la temperatura, il numero massimo di token, il timeout e il numero di tentativi. La chiave API è fornita dal servizio IA, mantenetela riservata.
