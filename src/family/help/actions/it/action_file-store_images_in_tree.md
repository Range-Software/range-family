# Memorizza tutte le immagini nell'albero genealogico

Spostare tutte le immagini archiviate nella directory dei dati nel file dell'albero genealogico.

Ogni immagine spostata nell'albero genealogico viene ridotta per occupare al massimo 256 KB. L'applicazione chiede prima una conferma. L'albero genealogico deve essere salvato perché la modifica abbia effetto, i file immagine non più usati vengono rimossi dopo il salvataggio dell'albero.
