# Dati

Aprire la cartella dei dati nel gestore di file.

La cartella dei dati è la posizione predefinita dei file degli alberi genealogici e delle loro immagini. Se la sincronizzazione della directory dei dati è attivata nelle impostazioni dell'applicazione, il suo contenuto viene sincronizzato con il Cloud. L'azione si trova nel menu "File", sotto "Cartelle".
