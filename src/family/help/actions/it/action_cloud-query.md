# Interrogazione IA Cloud

Mostra o nascondi l'interrogazione IA Cloud.

L'interrogazione IA Cloud viene mostrata in un pannello agganciabile, in una scheda insieme alla chat IA. Digitare una domanda e premere Invio o fare clic su "Invia", scegliere la lingua della risposta sopra la conversazione. Alle domande risponde il servizio IA del Cloud, non è necessario configurare alcun agente IA, ma serve una sessione Cloud.

La risposta tiene conto dell'albero genealogico solo se il suo file è archiviato nella directory dei dati, la sincronizzazione della directory dei dati con il Cloud è attivata nelle impostazioni dell'applicazione e il file è già stato sincronizzato. Altrimenti una nota nella conversazione indica perché l'albero genealogico non è stato usato. Le modifiche non salvate e quelle non ancora sincronizzate con il Cloud non vengono considerate. Quando viene caricato un altro albero genealogico, le domande e le risposte precedenti vengono dimenticate.
