# Зберігати всі зображення в родинному дереві

Перемістити всі зображення, збережені в каталозі даних, у файл родинного дерева.

Кожне зображення, переміщене в родинне дерево, зменшується так, щоб займати не більше 256 КБ. Програма спершу запитує підтвердження. Щоб зміна набула чинності, родинне дерево потрібно зберегти, файли зображень, які більше не використовуються, видаляються після збереження дерева.
