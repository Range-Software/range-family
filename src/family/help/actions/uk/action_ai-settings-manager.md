# Менеджер налаштувань AI

Керувати AI-агентами, яких використовує AI-чат.

Для кожного AI-агента задайте тип API, ключ API, URL і модель, а за потреби також температуру, максимальну кількість токенів, час очікування та кількість повторних спроб. Ключ API надає AI-сервіс, зберігайте його в таємниці.
