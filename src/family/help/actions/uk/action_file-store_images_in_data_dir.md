# Зберігати всі зображення в теці даних

Перемістити всі зображення, збережені у файлі родинного дерева, в окремі файли в каталозі файлу родинного дерева.

Зберігання зображень в окремих файлах робить файл родинного дерева невеликим. Родинне дерево спершу має бути збережене у файл. Програма спершу запитує підтвердження. Щоб зміна набула чинності, родинне дерево потрібно зберегти.
