# AI-запит у Cloud

Показати або сховати AI-запит у Cloud.

AI-запит у Cloud відображається в доку, на вкладці разом з AI-чатом. Введіть запитання й натисніть Enter або клацніть "Надіслати", мову відповіді виберіть над розмовою. На запитання відповідає AI-сервіс Cloud, налаштовувати AI-агента не потрібно, але потрібен сеанс Cloud.

Відповідь враховує родинне дерево, лише якщо його файл збережено в каталозі даних, у налаштуваннях програми ввімкнено синхронізацію каталогу даних із Cloud і файл уже синхронізовано. Інакше примітка в розмові пояснить, чому родинне дерево не було використано. Незбережені зміни та зміни, ще не синхронізовані з Cloud, не враховуються. Після завантаження іншого родинного дерева попередні запитання й відповіді забуваються.
