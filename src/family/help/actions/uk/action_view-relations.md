# Зв'язки

Показати або сховати список зв'язків.

Список відображається в доку. Вибір зв'язку будує навколо нього діаграму родинного дерева посередині вікна. Зв'язки осіб, вибраних у списку осіб, виділяються й позначаються на смузі прокрутки. Фільтр над списком показує лише зв'язки, що містять усі введені слова. Якщо позначено "Завжди показувати виділені", виділені зв'язки залишаються видимими, навіть якщо не відповідають фільтру. Якщо позначено "Лише виділені", показуються лише зв'язки вибраних осіб.
