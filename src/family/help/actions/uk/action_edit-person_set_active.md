# Зробити вибрану особу активною

Зробити особу, вибрану у списку осіб, активною особою.

Активна особа відображається жирним шрифтом у списку осіб і передається AI-чату як особа, яка запитує, тож можна відповідати на запитання на кшталт "хто мої бабусі й дідусі". Має бути вибрано рівно одну особу.
