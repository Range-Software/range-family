# Ausgewählte Person als aktiv festlegen

Die in der Personenliste ausgewählte Person als aktive Person festlegen.

Die aktive Person wird in der Personenliste fett angezeigt und an den KI-Chat als die fragende Person übergeben, sodass Fragen wie "Wer sind meine Großeltern" beantwortet werden können. Es muss genau eine Person ausgewählt sein.
