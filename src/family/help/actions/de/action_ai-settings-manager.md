# KI-Einstellungsverwaltung

KI-Agenten verwalten, die vom KI-Chat verwendet werden.

Legen Sie für jeden KI-Agenten den API-Typ, den API-Schlüssel, die URL und das Modell fest, optional auch die Temperatur, die maximale Anzahl an Tokens, das Zeitlimit und die Anzahl der Wiederholungen. Der API-Schlüssel wird vom KI-Dienst bereitgestellt, halten Sie ihn geheim.
