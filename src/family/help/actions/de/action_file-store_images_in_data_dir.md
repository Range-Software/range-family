# Alle Bilder im Datenordner speichern

Alle in der Stammbaumdatei gespeicherten Bilder in separate Dateien im Verzeichnis der Stammbaumdatei verschieben.

Das Speichern von Bildern in separaten Dateien hält die Stammbaumdatei klein. Der Stammbaum muss zuerst in einer Datei gespeichert sein. Die Anwendung fragt zuerst nach einer Bestätigung. Damit die Änderung wirksam wird, muss der Stammbaum gespeichert werden.
