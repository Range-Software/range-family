# Alle Bilder im Stammbaum speichern

Alle im Datenverzeichnis gespeicherten Bilder in die Stammbaumdatei verschieben.

Jedes in den Stammbaum verschobene Bild wird auf höchstens 256 KB verkleinert. Die Anwendung fragt zuerst nach einer Bestätigung. Damit die Änderung wirksam wird, muss der Stammbaum gespeichert werden, nicht mehr verwendete Bilddateien werden nach dem Speichern des Stammbaums entfernt.
