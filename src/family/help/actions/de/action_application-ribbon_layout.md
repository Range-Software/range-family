# Menüband-Layout

Befehle in einem Menüband statt in Menüs und Symbolleisten anzeigen.

Das Menüband gruppiert Befehle auf den Seiten "Stammbaum", "Personen", "Beziehungen" und "Cloud und KI". Das Menü "Datei", "Speichern", Cloud, Anwendungseinstellungen und Hilfe bleiben in der Zeile mit den Seitenregistern. Ein Doppelklick auf ein Register klappt das Menüband auf seine Register zusammen. Die Auswahl wird gespeichert.
