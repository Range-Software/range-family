# Daten

Den Datenordner im Dateibrowser öffnen.

Der Datenordner ist der Standardspeicherort von Stammbaumdateien und ihren Bildern. Wenn die Synchronisierung des Datenverzeichnisses in den Anwendungseinstellungen eingeschaltet ist, wird sein Inhalt mit der Cloud synchronisiert. Die Aktion befindet sich im Menü "Datei" unter "Ordner".
