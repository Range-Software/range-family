# Disposition en ruban

Afficher les commandes dans un ruban au lieu des menus et des barres d'outils.

Le ruban regroupe les commandes sur les pages "Arbre généalogique", "Personnes", "Relations" et "Cloud et IA". Le menu "Fichier", "Enregistrer", le Cloud, les paramètres de l'application et l'aide restent sur la ligne des onglets de page. Double-cliquez sur un onglet pour réduire le ruban à ses onglets. Le choix est mémorisé.
