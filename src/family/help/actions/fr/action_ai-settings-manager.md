# Gestionnaire des paramètres IA

Gérer les agents IA utilisés par la discussion IA.

Pour chaque agent IA, définissez le type d'API, la clé d'API, l'URL et le modèle, et éventuellement la température, le nombre maximal de jetons, le délai d'attente et le nombre de nouvelles tentatives. La clé d'API est fournie par le service d'IA, gardez-la confidentielle.
