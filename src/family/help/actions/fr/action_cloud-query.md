# Requête IA Cloud

Afficher ou masquer la requête IA Cloud.

La requête IA Cloud s'affiche dans un dock, en onglet avec la discussion IA. Saisissez une question et appuyez sur Entrée ou cliquez sur "Envoyer", choisissez la langue de la réponse au-dessus de la conversation. Les questions reçoivent une réponse du service d'IA du Cloud, aucun agent IA ne doit être configuré, mais une session Cloud est nécessaire.

La réponse tient compte de l'arbre généalogique uniquement si son fichier est stocké dans le répertoire de données, si la synchronisation du répertoire de données avec le Cloud est activée dans les paramètres de l'application et si le fichier a déjà été synchronisé. Sinon, une note dans la conversation indique pourquoi l'arbre généalogique n'a pas été utilisé. Les modifications non enregistrées et celles pas encore synchronisées avec le Cloud ne sont pas prises en compte. Lorsqu'un autre arbre généalogique est chargé, les questions et réponses précédentes sont oubliées.
