# Stocker toutes les images dans l'arbre généalogique

Déplacer toutes les images stockées dans le répertoire de données vers le fichier de l'arbre généalogique.

Chaque image déplacée dans l'arbre généalogique est réduite pour occuper au maximum 256 Ko. L'application demande d'abord une confirmation. L'arbre généalogique doit être enregistré pour que la modification prenne effet, les fichiers image qui ne sont plus utilisés sont supprimés une fois l'arbre enregistré.
