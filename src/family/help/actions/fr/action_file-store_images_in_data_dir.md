# Stocker toutes les images dans le dossier de données

Déplacer toutes les images stockées dans le fichier de l'arbre généalogique vers des fichiers distincts dans le répertoire du fichier de l'arbre généalogique.

Stocker les images dans des fichiers distincts permet de garder le fichier de l'arbre généalogique petit. L'arbre généalogique doit d'abord être enregistré dans un fichier. L'application demande d'abord une confirmation. L'arbre généalogique doit être enregistré pour que la modification prenne effet.
