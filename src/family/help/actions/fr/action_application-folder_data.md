# Données

Ouvrir le dossier des données dans l'explorateur de fichiers.

Le dossier des données est l'emplacement par défaut des fichiers d'arbres généalogiques et de leurs images. Lorsque la synchronisation du répertoire de données est activée dans les paramètres de l'application, son contenu est synchronisé avec le Cloud. L'action se trouve dans le menu "Fichier", sous "Dossiers".
