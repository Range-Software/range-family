# Cloud AI query

Show or hide the Cloud AI query.

The Cloud AI query is shown in a dock, tabbed with the AI chat. Type a question and press Enter or click "Send", choose the language of the answer above the conversation. Questions are answered by the AI service of Cloud, no AI agent has to be configured, but a Cloud session is required.

The answer takes the family tree into account only if its file is stored in the data directory, synchronization of the data directory with Cloud is turned on in the application settings and the file has already been synchronized. Otherwise a note in the conversation tells why the family tree was not used. Unsaved changes and changes not yet synchronized to Cloud are not taken into account. When another family tree is loaded, previous questions and answers are forgotten.
