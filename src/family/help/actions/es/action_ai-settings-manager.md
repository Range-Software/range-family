# Administrador de configuración de IA

Administrar los agentes de IA que utiliza el chat de IA.

Para cada agente de IA, configure el tipo de API, la clave de API, la URL y el modelo y, opcionalmente, la temperatura, el número máximo de tokens, el tiempo de espera y el número de reintentos. La clave de API la proporciona el servicio de IA, manténgala en privado.
