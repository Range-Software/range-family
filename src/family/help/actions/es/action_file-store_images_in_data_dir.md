# Almacenar todas las imágenes en el directorio de datos

Mover todas las imágenes almacenadas en el archivo del árbol genealógico a archivos independientes en el directorio del archivo del árbol genealógico.

Almacenar las imágenes en archivos independientes mantiene pequeño el archivo del árbol genealógico. Primero, el árbol genealógico debe guardarse en un archivo. La aplicación pide primero una confirmación. El árbol genealógico debe guardarse para que el cambio surta efecto.
