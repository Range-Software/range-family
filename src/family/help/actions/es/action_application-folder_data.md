# Datos

Abrir la carpeta de datos en el explorador de archivos.

La carpeta de datos es la ubicación predeterminada de los archivos de árboles genealógicos y sus imágenes. Si la sincronización del directorio de datos está activada en la configuración de la aplicación, su contenido se sincroniza con Cloud. La acción se encuentra en el menú "Archivo", en "Carpetas".
