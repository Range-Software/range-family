# Almacenar todas las imágenes en el árbol genealógico

Mover todas las imágenes almacenadas en el directorio de datos al archivo del árbol genealógico.

Cada imagen movida al árbol genealógico se reduce para ocupar como máximo 256 KB. La aplicación pide primero una confirmación. El árbol genealógico debe guardarse para que el cambio surta efecto, los archivos de imagen que ya no se usan se eliminan una vez guardado el árbol.
