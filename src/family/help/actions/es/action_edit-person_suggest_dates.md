# Sugerir fechas de nacimiento y fallecimiento

Sugerir las fechas de nacimiento y fallecimiento de las personas seleccionadas a partir de las fechas de sus familiares.

Las fechas se estiman a partir de las fechas conocidas de la persona, de las relaciones en las que la persona es pareja y de los hijos. Se abre un diálogo con las fechas sugeridas para cada persona seleccionada.
