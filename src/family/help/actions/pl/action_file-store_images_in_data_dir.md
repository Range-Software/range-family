# Przechowuj wszystkie obrazy w katalogu danych

Przenieść wszystkie zdjęcia zapisane w pliku drzewa genealogicznego do osobnych plików w katalogu pliku drzewa genealogicznego.

Przechowywanie zdjęć w osobnych plikach sprawia, że plik drzewa genealogicznego pozostaje mały. Drzewo genealogiczne musi być najpierw zapisane do pliku. Aplikacja najpierw prosi o potwierdzenie. Aby zmiana zaczęła obowiązywać, drzewo genealogiczne musi zostać zapisane.
