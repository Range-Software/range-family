# Ustaw wybraną osobę jako aktywną

Ustaw osobę wybraną na liście osób jako osobę aktywną.

Aktywna osoba jest wyświetlana pogrubioną czcionką na liście osób i przekazywana do czatu AI jako osoba, która pyta, dzięki czemu można odpowiadać na pytania takie jak "kim są moi dziadkowie". Musi być wybrana dokładnie jedna osoba.
