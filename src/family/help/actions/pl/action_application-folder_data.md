# Dane

Otworzyć folder danych w przeglądarce plików.

Folder danych jest domyślną lokalizacją plików drzew genealogicznych i ich zdjęć. Gdy w ustawieniach aplikacji włączona jest synchronizacja katalogu danych, jego zawartość jest synchronizowana z Cloud. Akcja znajduje się w menu "Plik" w "Foldery".
