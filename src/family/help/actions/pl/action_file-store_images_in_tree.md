# Przechowuj wszystkie obrazy w drzewie genealogicznym

Przenieść wszystkie zdjęcia zapisane w katalogu danych do pliku drzewa genealogicznego.

Każde zdjęcie przeniesione do drzewa genealogicznego jest zmniejszane tak, aby zajmowało najwyżej 256 KB. Aplikacja najpierw prosi o potwierdzenie. Aby zmiana zaczęła obowiązywać, drzewo genealogiczne musi zostać zapisane, nieużywane już pliki zdjęć są usuwane po zapisaniu drzewa.
